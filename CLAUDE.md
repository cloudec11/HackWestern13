# CLAUDE.md

This repo is built by four Claude agents working in parallel. Before doing anything:

1. Read `AGENTS.md` (rules, lanes, logging) and `TASKS.md` (assignments).
2. Confirm with your human which agent you are (agent-1 … agent-4). Do not guess.
3. Stay in your lane, and log every change with `python scripts/log.py add ...`.
